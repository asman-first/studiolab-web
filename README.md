# Studiolab Technologies — сайт studiolab.ae

Статический многостраничный сайт без сборки и зависимостей: HTML, один CSS и один JS.
Тексты основаны на текущем studiolab.ae и переписаны короче и чище.

## Структура

```
index.html        Главная: офферы с ценами, сравнения «было/стало»
services.html     Выбор услуги: 8 карточек, бесплатная консультация, FAQ (старые якоря #video и т.п. перенаправляются)
services/         Отдельная страница каждой услуги: sales-agent, employees, video, avatars, photoshoot, dubbing, websites, apps, automation
about.html        О студии
expertise.html    Экспертиза, процесс, стек
portfolio.html    6 продуктов студии
team.html         Команда и принципы
blog.html         Журнал (список статей)
contact.html      Контакты и форма
404.html          Страница «не найдено»
ar/               Арабская версия всех страниц (RTL)
ru/               Русская версия всех страниц
                  Переключатель языков в шапке ведёт на ту же страницу на двух других языках
assets/css/styles.css   Вся дизайн-система (токены в :root)
assets/js/main.js       Меню, анимации, счётчики, калькуляторы, фон героя, формы, номер WhatsApp
assets/img/             Фавикон, OG-картинка (PNG для соцсетей, SVG-исходник)
partials/               Общие шапка и подвал
scripts/sync-partials.mjs  Копирует шапку и подвал во все страницы
robots.txt, sitemap.xml
```

## Запуск локально

```bash
python -m http.server 5173
```

Затем откройте http://localhost:5173. Можно и просто открыть `index.html` двойным кликом.

## Как менять шапку или подвал

Правьте `partials/header.html` или `partials/footer.html` (арабские версии: `partials/header.ar.html`, `partials/footer.ar.html`; русские: `partials/header.ru.html`, `partials/footer.ru.html`), затем выполните:

```bash
node scripts/sync-partials.mjs
```

Скрипт заменит блоки между `<!-- @header -->` и `<!-- /@header -->` (и так же для подвала) во всех страницах, в том числе в `ar/` и `ru/`, сам отметит активный пункт меню и подставит в переключатель языков ссылки на ту же страницу на других языках (токены `{{alt:en}}`, `{{alt:ar}}`, `{{alt:ru}}` в шапке).

Страницы в подпапке `services/` (и `ar/services/`, `ru/services/`) обрабатываются тем же скриптом:
относительные ссылки в шапке и подвале получают префикс `../` автоматически, а пункт «Услуги» в меню
подсвечивается на всех страницах услуг. Новую услугу проще всего добавить, скопировав одну из этих страниц
в трёх языках и добавив карточку на главную и на `services.html`.

## Номер WhatsApp (важно до запуска)

Все кнопки WhatsApp берут номер из одной константы в начале `assets/js/main.js`:

```js
const WHATSAPP_NUMBER = "971553321026";
```

Номер указан в международном формате без плюса и пробелов (+971 55 332 1026).
У каждой кнопки свой заготовленный текст сообщения в атрибуте `data-wa-text`,
по нему видно, с какой услуги пришёл клиент.

### Кнопки WhatsApp

Любой элемент с `data-wa` получает ссылку wa.me с текстом из `data-wa-text`; если у него есть класс `btn`,
скрипт сам добавляет иконку WhatsApp (класс `btn--wa` делает кнопку зелёной). Таблица
`<table class="price-table" data-wa-service="…">` получает кнопку WhatsApp в каждой строке с названием пакета
и ценой в сообщении. Кнопка с `data-wa-calc` внутри калькулятора подставляет в сообщение выбранную конфигурацию
(количество видео, минуты, языки, тариф, сумму). Шаблоны сообщений лежат в `assets/js/main.js`, объект `STRINGS`.

## Цены

Все цены лежат прямо в HTML на `services.html` и `index.html`.
Бесплатная консультация (звонок 30 минут или визит в студию на 60 минут) описана в секции `#consultation`
на `services.html`, в карточке «С чего начать» на главной, в FAQ и в блоке контактов — менять нужно сразу
в трёх языках (корень, `ar/`, `ru/`). График работы (Пн–Пт, в выходные заявки в WhatsApp) прописан в подвале
и на странице контактов.
Калькулятор дубляжа берёт ставки из атрибутов `data-rate` и `data-min` у кнопок тарифов,
лестница скидок за языки (5 языков −20%, 10+ −30%) и лестница цен на видео заданы в `assets/js/main.js`.
Подписи калькуляторов и сообщения форм на трёх языках лежат там же, в объекте `STRINGS`;
язык страницы определяется по атрибуту `<html lang>`.

## Заявки: только WhatsApp

Онлайн-формы на сайте нет (решение от 3 ноября 2026 года). Все заявки приходят в WhatsApp студии,
номер задан в `assets/js/main.js` (`WHATSAPP_NUMBER`). На странице «Контакты» вместо формы стоит панель
с темами: каждая тема открывает чат с готовым первым сообщением, ниже кнопки «Написать в WhatsApp» и «Позвонить».
Серверной части и внешних сервисов для приёма заявок не нужно.

## Публикация

Сейчас сайт опубликован на GitHub Pages из репозитория `asman-first/studiolab-web`:
https://asman-first.github.io/studiolab-web/ (арабская версия: `/ar/`, русская: `/ru/`).
Каждый `git push` в ветку `main` обновляет сайт примерно за минуту.
Привязать домен studiolab.ae: в настройках репозитория Pages → Custom domain, плюс CNAME-запись у регистратора.

Подойдёт любой статический хостинг: Cloudflare Pages, Netlify, Vercel, GitHub Pages.
Канонические адреса и sitemap используют «чистые» URL вида `/about`, как на текущем сайте.
Cloudflare Pages, Netlify и Vercel по умолчанию отдают `about.html` по адресу `/about`.
На Vercel включите `cleanUrls: true` в `vercel.json`. На Apache или Nginx нужно правило перезаписи.

## Что стоит дополнить

- **Статьи журнала.** Есть только заголовки и анонсы, отдельных страниц со статьями нет.
- **Почта.** На текущем сайте email не указан, поэтому его нет и здесь.
- **Фото и имена команды.** Страница команды описывает роли и принципы без персоналий.
- **Скриншоты продуктов.** Карточки портфолио сейчас текстовые.
- **Аналитика.** Счётчики (GA4, Plausible и т. п.) не подключены.
